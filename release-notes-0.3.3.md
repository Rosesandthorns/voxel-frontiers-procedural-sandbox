Biome 0.3.3 fixes the version display and oxygen HUD, and gives seagulls proper flight.

- The menu footer now shows the running build version instead of the hard-coded 0.2.10. The launcher initial display and EOS client version use the same build metadata.
- Oxygen appears above health and hunger without resizing the bars or moving the hotbar.
- Seagulls alternate between perching/floating and sustained flight, with takeoff, landing and flapping wings. Flight animation is synchronized to multiplayer guests.

Validation: real packaged handoffs into 0.3.0, 0.3.1 and 0.3.2; launcher selection, backups and Windows file-lock tests; seagull takeoff/landing and wing-animation tests; TypeScript and packaged gameplay checks.
